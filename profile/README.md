# DiamaneOS

A security and privacy-focused custom Android-based OS.

- **Based on GrapheneOS**, as a partial port: the supported devices do not meet
  GrapheneOS's [device requirements](https://grapheneos.org/faq#future-devices),
  so DiamaneOS does not offer the same security as GrapheneOS on GrapheneOS's
  own devices. The [threat model](https://github.com/DiamaneOS/diamaneos-tools/blob/main/docs/THREAT_MODEL.md)
  lists what is protected and what is not.
- **Supported devices:** Fairphone 6.
- **Independent.** Not affiliated with or endorsed by GrapheneOS or any device
  maker.
